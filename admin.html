🐠 Store Admin Sami Fishes & Aquariums

Add products, change prices, remove items — changes save to your Google Sheet and appear on the website automatically (allow a few minutes).

⚙️ One-time setup needed

This panel saves changes to your Store Products Google Sheet through a free Google Apps Script. Set it up once:

  1. Open the Store Products Google Sheet (in your Drive folder)
  2. Menu: Extensions → Apps Script
  3. Paste the code from apps-script-code.txt (in your sami fish folder) and change the SECRET_KEY to your own password
  4. Deploy → New deployment → Web app — Execute as: Me, Access: Anyone → Deploy → copy the URL ending in /exec
  5. Open admin.html in a text editor and paste that URL into APPS_SCRIPT_URL below the word SETTINGS — or send it to Claude and it will be done for you

Tip: ask Claude to walk through this with you in the browser — it takes about 4 minutes.
